# Cross-language contract fixture

Generated by `node tools/build-bundle-fixture.mjs` using the real Rust extractors,
MVT/PMTiles encoder, deterministic tar and bundle writer. Input is the existing
`test/fixture.osm` grid plus an explicitly tagged **test-only** `123 Main Street`
address and an alternate street name. Repeated legacy test way ids are normalised
and isolated far-away place nodes are omitted to keep the bbox on the grid.
Routing `.gph` bytes come from the existing
real `test/fixture.valhalla.tar`, normalised into deterministic ustar. No fake
Valhalla tiles are used in JS/WASM contract tests. This avoids requiring the
native C++ builder in the JS gate; the server's API pipeline test separately
uses a stub, and the Docker smoke uses the pinned real binary.

The four standalone files and the transport bundle describe the same build.
The timestamp is fixed for reproducibility; input/artifact SHA-256 values are
generated, not mocked. Do not use this hand-made test geography for navigation.
